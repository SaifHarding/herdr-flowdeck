Flowdeck hero image kit

Everything ChatGPT needs to make a clean hero image: the real logos, the sprites, a reference scene, and a short prompt.

How to use it

  1. Download the reference scene and the four assets below (PNG).
  2. Attach all five to a new ChatGPT message.
  3. Paste the prompt, pick a size, and send. Ask for a variation if the first one adds text, misspells the tagline or redraws a logo.
